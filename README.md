# Hacker News Posts Analysis

## 📌 Project Overview

This project was developed as part of my data analysis learning journey. The objective is to analyze Hacker News posts using Python in Google Colab and gain insights into user engagement, post popularity, and posting trends through exploratory data analysis and visualization.

## 🎯 Objectives

* Learn data cleaning and preprocessing techniques.
* Perform exploratory data analysis (EDA).
* Analyze post scores, comments, and user engagement.
* Create visualizations to better understand the dataset.
* Develop practical experience with Python data analysis libraries.

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib

## ▶️ How to Run

1. Clone this repository.
2. Open `hacker_news_posts.ipynb` using Google Colab or Jupyter Notebook.
3. Install the required Python libraries if needed.
4. Run the notebook cells in order to reproduce the analysis.
